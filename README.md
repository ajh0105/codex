# 스프링부트 입문 학습 웹사이트

초급자가 **게시판 / 회원가입 / 로그인** 기능을 스프링부트로 학습할 수 있도록 만든 정적 학습 사이트입니다.

## 포함 내용

- 7개 챕터 상세 강의 (개념 설명 + 실전 코드 + 암기 체크포인트)
- 챕터별 복습 문제 은행(총 50문항)
- 문제 수를 선택해 랜덤 퀴즈 생성 + 즉시 채점/해설
- PC / 태블릿 / 모바일 반응형 UI

## 로컬 실행

정적 파일이므로 별도 빌드 없이 브라우저에서 `index.html`을 열면 됩니다.

더 안전하게 테스트하려면 간단 서버를 실행하세요.

```bash
python -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속.

## GitHub Pages 배포 방법

1. 저장소를 GitHub에 push
2. GitHub 저장소 → **Settings** → **Pages** 이동
3. **Build and deployment**
   - Source: `Deploy from a branch`
   - Branch: `main` (또는 현재 브랜치) / `/root`
4. 저장 후 1~2분 대기
5. 발급된 URL 접속

## 학습 추천 루틴

1. 챕터를 순서대로 읽으며 코드 타이핑
2. 챕터 완료 후 해당 챕터 필터로 퀴즈 10문제 풀이
3. 전체 필터로 20~30문제 랜덤 복습
4. 틀린 문제의 챕터로 돌아가 재학습
